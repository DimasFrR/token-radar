Token Radar ranks 200 pre-token DeFi protocols by implied launch value — TVL × a category multiple calibrated from the snapshot's own tokenized protocols × growth × maturity × chains — and gives each protocol a concrete farm plan with costs and times. The dashboard is a static page with a sortable board, a detail view for every protocol, and category/token-status filters.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
